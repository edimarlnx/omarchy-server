# Desktop reference install (Omarchy 4.0.1, 2026-08-28)

VM `ref` (`vm.sh ref`): QEMU/KVM q35, 4 vCPU, 8 GiB, OVMF 4M without Secure
Boot, 40 GiB virtio disk, official `omarchy-4.0.1.iso` (sha256 OK) + `cidata`
generated by `mkcidata.sh --profile desktop` (no interactive configurator).
qcow2 snapshot `reference` taken after collection.

## Notes for the server profile

- The loader (limine) is half of the boot time (6.4 s): the menu timeout. On a
  server the timeout goes to zero, keeping only the fallback entry.
- `sshd` is already enabled by the "Configuring SSH access" phase when the
  `cidata` drive carries `authorized_keys`; a headless server via `cidata` is
  the natural upstream path.
- The `@factory` snapshot and `limine-snapper-sync` are the rollback baseline;
  immutability is the next step.
- 14 GB used vs 8 GB installed: `@pkg` holds the install package cache; the
  server profile prunes it (`paccache`) before the factory snapshot.
